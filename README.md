# GTA-SA-UNITY
GTA SA (SAN ANDREAS) all in unity with most stuff + comes with a premade gta san andreas path.
# How do i use this? Load in the game first then click "Change path to GTA" and click on GTA SAN ANDREAS and click "Select current folder" and boom.
